# 文档编写规范

更新时间：2026-08-14 14:01（Asia/Shanghai）

- 交接入口使用 `00` 至 `06` 连续编号。
- 活动迭代放在 `docs\01-当前工作\Ixxx-迭代名称`；完成或取消后移入 `docs\07-迭代归档\YYYY`。
- 新迭代编号扫描当前工作与归档后取最大值加一，不重复、不回收、不重排。
- 迭代总览必须为 `00-迭代总览.md`，记录状态、负责人、优先级、目标、任务、阻塞、验收、完成内容、待处理、提交和阅读顺序。
- 同一信息只保留一个事实源；当前状态、待办、路线图、技术架构和迭代证据不得复制完整内容。
- 当前状态或待办变化时更新对应入口文档的上海时区时间。
- 不创建空模板；实施、执行、验收、审查记录仅在已有实际内容时创建。
- 本次 `docs\` 仅本地保留，禁止提交；通过 `.git\info\exclude` 排除。
