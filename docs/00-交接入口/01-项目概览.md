# 项目概览

更新时间：2026-08-20 22:26（Asia/Shanghai）

## 项目定位

本项目为 DeepSeek Harness 提供 Windows x64、macOS Apple Silicon（arm64）、macOS Intel（x64）与 Linux x64 桌面启动器。通过 Electron 管理本地 DSH Web 服务与窗口，使非技术用户无需安装系统 Node 或执行命令行。

## 当前阶段

当前版本基线为 `v1.0.12`。Windows x64、macOS arm64/x64 与 Linux x64 的远端构建、打包和冒烟已分别验证；本补丁版发布桥接闭包、运行时回退、插件生命周期、跨架构更新及跨平台发布测试修复。

## 核心能力

- 内置 Node 24 运行时与固定 DSH 运行闭包。
- 启动 DSH Web UI 并使用随机 loopback 端口。
- 桌面窗口、单实例、托盘、错误提示和受控关闭。
- Windows x64 安装器与 ZIP、macOS arm64/x64 的 DMG 与 ZIP，以及 Linux x64 的 AppImage 与 deb。
- 随包装配六个功能插件与 dshmarket 插件市场的离线仓库，首次启动写入用户 Web profile。
- 随包提供 pnpm，兼容 code-ui 与 dshmarket 的 `dsh plugin add` 在线安装。

## 稳定边界

- 不修改 DSH 上游仓库。
- 不开放局域网访问；服务只监听 `127.0.0.1`。
- 桌面更新仅由用户从托盘手动检查和下载，启动时不自动检查；插件更新继续复用 DSH profile 插件协议。
- 用户数据保留在 `%USERPROFILE%\.dsh`，升级和卸载不得删除。
