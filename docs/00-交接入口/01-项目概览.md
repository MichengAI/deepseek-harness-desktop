# 项目概览

更新时间：2026-08-14 18:55（Asia/Shanghai）

## 项目定位

本项目为 DeepSeek Harness 提供 Windows x64、macOS Apple Silicon（arm64）与 macOS Intel（x64）桌面启动器。通过 Electron 管理本地 DSH Web 服务与窗口，使非技术用户无需安装系统 Node 或执行命令行。

## 当前阶段

Windows `v0.1.0` 已发布。三平台构建、打包与冒烟已验证；当前迭代为等待 Apple 签名与公证凭据的 `I002-macOS桌面端支持`。

## 核心能力

- 内置 Node 24 运行时与固定 DSH 运行闭包。
- 启动 DSH Web UI 并使用随机 loopback 端口。
- 桌面窗口、单实例、托盘、错误提示和受控关闭。
- Windows x64 安装器与 ZIP，以及 macOS arm64、x64 的 DMG 与 ZIP。

## 稳定边界

- 不修改 DSH 上游仓库。
- 不开放局域网访问；服务只监听 `127.0.0.1`。
- 不实现自动更新、插件市场或 `file:// + IPC` 桌面表层。
- 用户数据保留在 `%USERPROFILE%\.dsh`，升级和卸载不得删除。
