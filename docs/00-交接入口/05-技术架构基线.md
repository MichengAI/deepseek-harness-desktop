# 技术架构基线

更新时间：2026-08-14 18:55（Asia/Shanghai）

当前生效的技术硬约束：

- Windows x64、macOS arm64 与 macOS x64，Electron 本地 HTTP 壳。
- 官方 Node 24 与固定上游提交构建的 DSH 运行闭包。
- DSH 使用 `--port 0`，仅监听 `127.0.0.1`。
- 仅加载经校验的 loopback HTTP 地址。
- `nodeIntegration: false`、`contextIsolation: true`。
- 正常退出走受控关闭通道；超时仅按 PID 兜底，不全局结束 `node.exe`。
- 不记录密钥、授权请求头、会话正文或模型输出。
- macOS 标签发布必须完成 Apple Developer 签名与公证；缺少凭据时禁止公开发布。

详细唯一事实源：`docs\03-技术架构\00-桌面启动器架构基线.md`。
