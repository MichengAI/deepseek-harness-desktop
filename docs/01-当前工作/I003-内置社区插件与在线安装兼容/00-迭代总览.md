## 目标与业务边界

把 6 个社区 npm 包装进桌面安装包，首启写入用户 Web profile。code-ui 与 dshmarket 继续走 `dsh plugin add` 在线安装/更新。社区插件不得进入 DSH 安装目录 `node_modules`，否则安装目录优先解析会挡住 profile 里的新版本。

## 验收标准

- 新用户首次启动后，Web profile 含六个插件或明确的补种失败日志
- 已装 `@michengai/dsh-codex-suite` 时不重复写入子插件
- 打包应用的 `resources\\node` 可执行 `pnpm --version`
- code-ui / dshmarket 的 `dsh plugin add` 仍写入 `~/.dsh/profiles/web`
- 安装器可选目录，选完后路径自动带上 `dsh-codex-desktop`
- DSH 缺 peer 时能自动补齐并写出完整启动日志
- 窗口默认最大化
- 新安装包首启复制 `resources\\dsh-runtime`，不再现场安装整棵官方依赖
