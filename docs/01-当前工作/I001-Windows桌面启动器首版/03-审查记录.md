# I001 审查记录

更新时间：2026-08-14 16:12（Asia/Shanghai）

## 已确认结论

| 主题 | 结论 | 理由 |
|---|---|---|
| 桌面路线 | Electron 本地 HTTP 壳 | 复用现有 DSH Web UI，覆盖窗口和托盘需求。 |
| 端口 | `--port 0` | 避免固定端口冲突。 |
| Node | 内置官方 Node 24 | 满足 DSH 版本约束，避免系统依赖。 |
| DSH 来源 | 固定上游提交构建 | 目标 npm 包未发布。 |
| 关闭 | IPC 请求 DSH 优雅关闭，超时后终止本应用 PID | 不枚举或终止其他 `node.exe`。 |
| 数据 | 沿用 `%USERPROFILE%\.dsh` | 保持与独立 DSH CLI 的会话、凭据和设置连续。 |

## 后续审查重点

- 最小运行闭包是否脱离上游工作树可运行。
- Windows 原生模块和 Electron 打包后的兼容性。
- 干净 Windows 安装、卸载和升级后数据连续性。
- 首次远端 CI 的打包后冒烟结果。
- 上游工作区依赖闭包在版本升级后是否仍可由装配脚本完整导出。
