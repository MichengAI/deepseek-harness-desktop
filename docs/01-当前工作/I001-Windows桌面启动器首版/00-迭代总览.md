## 目标与业务边界

交付无需系统 Node 的 Windows x64 DSH Electron 启动器。桌面层不重写 DSH Web UI，不修改上游仓库，也不覆盖用户 DSH 数据。

## 任务清单

1. 完成 DSH 运行闭包、Electron 主进程及本地打包验证。
2. 补充 Windows 实机安装验收与 CI 打包验证。
3. 明确首版代码签名和发布策略。

## 阻塞事项

暂无外部阻塞。

## 验收标准

- 无系统 Node 的 Windows 10、Windows 11 可启动安装器和便携 ZIP。
- DSH 仅监听 `127.0.0.1`，随机端口根页面返回 HTTP 200。
- 第二次启动仅激活已有窗口；正常退出后无启动器遗留的 `node.exe`。
- 中文和空格安装路径可用；升级、卸载不删除 `%USERPROFILE%\.dsh`。
- 安全配置和日志脱敏符合 `docs\03-技术架构\00-桌面启动器架构基线.md`。
- 暂存区和发布源码不包含证书、密钥、安装器或用户日志。
