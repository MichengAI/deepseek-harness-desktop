# I002-macOS桌面端支持迭代总览

状态：进行中

负责人：Codex

优先级：P1

更新时间：2026-08-14 19:16（Asia/Shanghai）

## 目标与业务边界

在不改变 DSH Web UI 和既有 Windows 发布能力的前提下，增加 macOS Apple Silicon（arm64）与 Intel（x64）的原生 DMG、ZIP 打包和 CI 冒烟。当前公开未签名、未公证测试版；Apple 签名与公证为后续正式发布能力。

## 任务清单

1. 按平台与架构校验随包 Node 运行时。
2. 增加 macOS 打包目标、冒烟检查与公证钩子。
3. 将 CI 改为三平台构建和单一 Release 汇总。
4. 未配置 Apple 凭据时允许标签发布未签名测试包，并在 README 说明风险与安装限制。
5. 创建新版本标签，验收三平台制品汇总到 GitHub Release。

## 阻塞事项

无。Apple Developer 签名证书、钥匙串密码及公证凭据为后续正式发布可选配置。

## 验收标准

- macOS arm64 与 x64 均从本机构建的 DSH 运行时生成 DMG 和 ZIP。
- 打包应用启动后 DSH 仅监听 `127.0.0.1`，根页面与前端资源均返回 HTTP 200。
- 应用退出后无遗留 DSH 引导进程。
- 未配置 Apple 凭据时，标签发布仍能将明确标注风险的未签名、未公证 macOS 测试包上传到 GitHub Release。
- 配置完整 Apple 凭据时，标签发布自动导入签名证书并执行 Apple 公证。
- Windows x64 打包与既有冒烟检查继续通过。

## 已完成内容

- 已补充 macOS arm64、x64 的 Node 24.19.0 SHA256 校验配置与单元测试。
- 已增加 macOS `.app` 冒烟脚本和公证钩子。
- 已将 CI 改为 Windows x64、macOS arm64、macOS x64 三平台构建，并由独立 Release 任务汇总制品。
- 本地 Windows 目录打包和 15 项单元测试通过。
- 远端 CI 已验证 Windows x64、macOS arm64、macOS x64 的原生构建、打包和冒烟全部通过。
- 已修复上游 DSH 在 Intel macOS 上被 pnpm 11.20 原生执行包校验阻断的问题：DSH 构建通过 `npm exec` 固定使用其声明的 pnpm 11.7，桌面端保持 pnpm 11.20。
- 已将未配置 Apple 凭据时的标签发布改为未签名、未公证测试包，并在 README 标注 Gatekeeper 风险和仅测试限制。
